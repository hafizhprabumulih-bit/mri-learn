MODUL 9: Optimasi Protokol dan Membaca Layar Konsol

Media belajar, bukan untuk keputusan klinis. Prasyarat: M04B. Disarankan: M03A (TSE), M08A (kompromi artefak).

  • Menjelaskan arti parameter di layar konsol.
  • Menghitung waktu pindai (TA) 2D dan mengoreksinya untuk TSE dan 3D.
  • Memperkirakan perubahan SNR.
  • Menilai kompromi (trade-off) parameter.
  • Menunjukkan fungsi tab konsol dan sistem komputer.

Cek pemahaman

Tautan silang

  • Mengapa TA = waktu mengisi ruang-k: M04B T2.10 (Fakta 4)
  • SNR dan kompromi tingkat lanjut: M04C T3.8 (hanya tautan ke sini)
  • Menurunkan SAR sebagai kompromi: M07C A1 mode 3
  • Perbaikan artefak ada harganya: M08C T3.3
